# Amelie's Lavender Lounge

**The Little Things Club** — a cosy little adventure game made for Amelie, with love from Gabi. ♡

Play it at: https://gabifav.github.io/amelies-lavender-lounge/

On a phone, open the link and choose "Add to Home Screen" to install it like an app. After the first visit it also works offline.

Everything (art, music, sounds) is generated by the game itself — `index.html` is the whole game.
